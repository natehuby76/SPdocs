# StarPilot Docs

<span id="starpilot-official-documentation"></span>

This is the official StarPilot wiki for installation, supported hardware, features, and troubleshooting.

StarPilot is a standalone, community-driven [openpilot](https://github.com/commaai/openpilot) fork for comma 3, 3X, and 4. It adds driving options, Galaxy device management, and vehicle support.
