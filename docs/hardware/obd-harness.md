# OBD-II Harness

{% include-markdown "./embed/see-car-guide.md" %}

If your car setup guide calls for an OBD-II harness, check the
[comma OBD-II Harness](https://comma.ai/shop/car-harness?harness=OBD-II).

The [Konik OBD2C connector](https://konik.ai/shop/obd2c-connector/) is a development
connector for CAN diagnostics with a panda.

Check the connector and what’s included. Confirm the [OBD-C cable](./obd-c.md) length required for your car.
